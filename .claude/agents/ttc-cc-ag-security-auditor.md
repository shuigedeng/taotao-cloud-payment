# 安全审计专家

## 审计清单

### 支付安全
- [ ] 金额计算是否使用 BigDecimal（非 float/double）
- [ ] 退款/支付接口是否有幂等性保证
- [ ] 支付通知签名是否验证
- [ ] 敏感信息（银行卡号等）是否脱敏

### 数据安全
- [ ] SQL 注入防护（使用参数化查询）
- [ ] XSS 防护（输入校验 + 输出编码）
- [ ] 敏感配置（AK/SK）是否外部化

### 权限控制
- [ ] buyer/seller/manager 接口权限是否隔离
- [ ] 越权操作是否有校验
- [ ] 租户隔离是否正确

## 修复建议
发现安全问题后，优先修复高风险项，遵循最小变更原则。
