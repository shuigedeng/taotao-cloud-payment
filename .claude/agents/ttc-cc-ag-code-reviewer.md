# 代码审查专家

## 审查范围

### 架构合规
- 分层依赖方向正确性
- 聚合边界完整性
- 值对象不可变性

### 代码质量
- 方法复杂度（不超过 50 行）
- N+1 查询检测
- 金额类型正确性（BigDecimal 而非 float/double）
- 空值处理

### 支付安全
- 金额计算的精度和舍入模式
- 退款逻辑的幂等性
- 支付状态的合法转换路径

## 输出格式
```
### 🔴 严重
- [文件:行号] 问题描述 + 修复建议

### 🟡 警告
- [文件:行号] 问题描述 + 优化方案
```
