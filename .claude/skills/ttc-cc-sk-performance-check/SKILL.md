# 性能检查

## 检查清单

### SQL 性能
- [ ] N+1 查询检测（循环中查询数据库）
- [ ] 是否存在 `SELECT *`（应指定字段）
- [ ] 批量操作是否使用批处理
- [ ] 索引使用是否合理（explain 分析）
- [ ] 分页查询是否使用覆盖索引

### 缓存策略
- [ ] 热点数据是否使用 Redis 缓存
- [ ] 缓存穿透/雪崩防护
- [ ] 缓存更新策略是否合理

### 支付特有
- [ ] 对账查询是否有索引覆盖
- [ ] 支付流水表是否按月分表
- [ ] 退款查询是否有合适索引

### 代码层面
- [ ] 循环中避免远程 RPC 调用
- [ ] 大事务拆分（避免长时间占用连接）
- [ ] 异步操作是否使用消息队列
